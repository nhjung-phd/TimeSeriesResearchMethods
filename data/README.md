# Data policy

`data/sample/`에는 저작권과 재배포 조건이 명확한 소량 자료만 저장합니다. `data/synthetic/`에는 코드로 생성한 합성 자료만 저장합니다.

원자료 다운로드 파일, 개인 API 키, 개인정보, 라이선스 미확인 데이터는 업로드 금지. 데이터마다 citation/URL, 관측기간, 수집일, 단위, 결측 처리, 라이선스를 명시하십시오.
- `finance/gold_historical_data.csv`: 금 일별 OHLC·거래량(2016-02-05~2026-01-30, 2,510행). 출처·라이선스 표기 없음(Yahoo `GC=F` 계열로 추정, 확인 필요). 재배포 가능 여부 확인 전까지 교육용 내부 사용을 전제로 한다.
